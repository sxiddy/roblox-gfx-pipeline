Owner (2026-10-26): "u dont have to make it exactly how the picture is, u can pose it according to what would suit this avatar better".

**Why:** the reference avatar (tall jacket, long hair) leans into frame; copying that pose on a chibi goth avatar gave a tiny body and a floating hand (garage v5, ~5/10).
**How to apply:** keep the reference's camera, set, lighting and grade, but pick the pose from the avatar's proportions and vibe. Still write the pose plan first ([[gfx-pose-plan-first]]). Related: [[roblox-gfx-pipeline]].
