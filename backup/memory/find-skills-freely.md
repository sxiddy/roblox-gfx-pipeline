Owner (2026-10-27): use any repo you need, and search and install skills with the vercel-labs `skills` CLI (`skills find <need>`, read via `skills use`, then `skills add <owner/repo@skill> -g -y --agent claude-code`) whenever a gap shows up. Describe the need, pick the most suitable one, and tell the owner which one.

**Why:** the owner wants the quality to match good Roblox animations and doesn't want to approve each tool.
**How to apply:** read a skill's text before installing it (third-party skills run with full permissions). Skip ones built for other engines (Three.js) or tied to paid outside services. Related: [[repo-library]], [[animation-pipeline-lessons]].
