The owner sends a different reference image almost every time and will not explain how to recreate it. Work out the camera, pose, background, lighting and colour grade from the image myself, then build and iterate. Never ask "how should it look". Ask only for a missing username.

**Why:** they said so on 2026-10-25, after a 6.5/10 GFX that still needed 7 tuning passes.
**How to apply:** follow the `roblox-gfx-match` skill: write a spec from the reference, build, compare previews side by side, fix the biggest differences, then ask for a score. Related: [[roblox-gfx-pipeline]], [[owner-rates-lower]], [[usage-cap]].
